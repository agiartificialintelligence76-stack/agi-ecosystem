How it works

Three steps, all on your side.

There's no server of ours in the path. Your device does the checking.

  1. 01

    Scrub, on your device

    Names, email addresses, phone numbers, card numbers, IBANs, ID numbers, API keys, passwords, private keys and seed phrases each become a keyed token, like [EMAIL_X3L7D2QA]. The map back stays on your device, encrypted.

  2. 02

    Check the machine

    The server must show a report signed by its own AMD chip. Your device checks it against AMD's root keys, built into CloakMesh: genuine hardware, approved code, debugging off, current firmware. If anything is off, nothing is sent.

  3. 03

    Talk end to end

    Then your device talks to that machine over AES-256-GCM. The network, the cloud host and any relay see only ciphertext. The answer comes back, and your real values are put back in, on your device.

The proof

How your device knows it's real.

Five checks, run by CloakMesh on your device before a single byte of your prompt leaves. Pass all five, or nothing is sent.

  1. AMD signed it.

    The server sends a report signed by its own AMD chip. CloakMesh checks the signature all the way up to AMD's root keys, which are built into the app, so nobody can stand in for AMD.

  2. This chip, current firmware.

    The chip's certificate must match the report, and its security patches must be at or above a required minimum.

  3. Approved code, locked down.

    The report holds a fingerprint of the code that started the machine. It must be on the approved list, with debugging and migration switched off.

  4. Its key lives inside.

    The report also carries the server's own key, created inside the sealed machine. A copy of someone else's report is useless.

  5. This connection belongs to that key.

    The server signs this very handshake with that key, so nobody can replay it or slip in between.

Tested against genuine AMD data (an EPYC Milan report and its certificates, a Turin certificate) and against dozens of forged and tampered reports.

Straight answers

What Phase 1 doesn't do yet.

  • GPUs

    Phase 1 checks the AMD machine itself (its processor and memory), so models run inside it. Checking NVIDIA confidential GPUs and Intel TDX machines is Phase 2, and it's what the biggest models need.

  • Not live yet

    The client, the encrypted connection, the server side and the filter are built and tested. The first servers come next, and the waitlist hears first.

  • A filter, not a mind reader

    It catches the formats and cues above, not every secret you could write in a sentence. You can always see exactly what will be sent before it goes.

  • Approved means checked, not perfect

    The proof shows which code is running, not that the code is good. That's why only published, reviewed code should ever be on the approved list.

FAQ

Questions.

Is CloakMesh live?

Not yet. Phase 1 (the client that checks the hardware, the encrypted connection, the server side and the filter) is built and tested. The first servers come next, and the waitlist hears first.

Do I have to trust AGI?

Not with your prompts: there's no server of ours in the path, and your device checks the hardware against AMD's keys, not ours. You do rely on AMD's hardware, as every confidential-computing service does, and on the approved code being published for anyone to check.

Can whoever runs the server read my prompt?

Not if the checks pass: the machine's memory is encrypted by its own processor, debugging is off, and its code is on the approved list. And your names, keys and numbers are tokens before they leave anyway.

Which hardware does it check?

AMD SEV-SNP machines with EPYC Milan, Genoa or Turin processors, on clouds such as Google Cloud's confidential VMs. NVIDIA confidential GPUs and Intel TDX come in Phase 2.

What does the filter catch?

Names when they're introduced (“I'm…”, “Dear…”) or seen before, email addresses, phone numbers, card numbers, IBANs, ID numbers, API keys, passwords, private keys, seed phrases, street addresses and more. It runs before anything is sent.

Can I run a server?

That's the plan: servers run on AMD SEV-SNP machines with approved code. Pick “Run a server” when you join, and you'll hear when it opens.

What will it cost?

It's not decided yet. With no gateway in the middle, there's one less thing to pay for. The waitlist hears first.
